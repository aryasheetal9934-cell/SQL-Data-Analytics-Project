# SQL Data Analytics Project

An end-to-end **SQL Data Analytics project** built using SQL Server to analyze customer, product, and sales data. The project focuses on transforming transactional data into meaningful business insights through structured SQL analysis.

The analysis covers **customer behavior, product and category performance, revenue, sales trends, ranking, segmentation, cumulative analysis, and performance reporting**.

### Tech Stack
**SQL Server | SSMS | Git | GitHub**

### SQL Skills
**Joins | Aggregations | GROUP BY | CTEs | Subqueries | Window Functions | Date Functions | CASE Statements**

### Project Structure
- `datasets/` — Source customer, product, and sales datasets
- `scripts/` — SQL scripts covering the complete analytical workflow
